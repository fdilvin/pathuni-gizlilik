# PATH-Uni — Gizlilik Politikası

Bu depo yalnızca PATH-Uni mobil uygulamasının gizlilik politikası sayfasını barındırır
(Google Play mağaza girişinde istenen "Gizlilik politikası URL'si").

Yayındaki adres: https://fdilvin.github.io/pathuni-gizlilik/

`index.html` elle düzenlenmez. Kaynağı uygulama deposundaki
`assets/content/informed-consent.json` dosyasıdır ve sayfa
`tools/build_privacy_page.ps1` script'i ile üretilir. Onam metni değiştiğinde
script yeniden çalıştırılıp üretilen dosya buraya kopyalanır.
